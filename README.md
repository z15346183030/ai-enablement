# 赵旭 — 帮一家公司把 AI 用起来

面向「企业内 AI 赋能」岗位的个人站点。单文件、零依赖、无构建。

线上地址：https://z15346183030.github.io/ai-enablement/

## 这个站在说什么

不是「我想加入一个 FDE 团队去客户现场」，而是「你们公司需要一个人把 AI 装进来，我就是那个人」。

所以叙事完全围绕一件事组织：

> 不做单点 demo，把 AI 接到现有的业务、数据、流程和人身上。

## 交互生成器的实现

纯前端规则引擎，不调用任何模型。三个维度组合后生成 14 行计划：

- `SIZE_MOVE` — 规模决定第一枪怎么打（小团队直接做工具 / 中型做样板 / 大公司先盘点）
- `IND_CUT` — 行业决定最容易见效的切口
- `PAIN_PROJ` / `PAIN_KPI` / `PAIN_RISK` — 痛点决定样板项目、验收指标和最大风险

点击生成时用 `setInterval` 逐行插入 DOM，做出流式输出的观感；行本身没有 CSS 动画，所以任何情况下内容都不会丢。

## 设计

- 暖白 `#fbfaf7` + 墨黑 `#15120f` + 橙红 `#e0431a`，编辑部风格
- 与前两个站刻意区分：`portfolio` 是浅色 Bento，`fde` 是深色控制台，这个是暖白编辑部
- 深色主题可切换（快捷键 `T`），记忆选择

## 技术

- 单文件 `index.html`，无框架、无依赖、无外部字体
- 滚动进度、渐入动画、能力矩阵状态徽章逐个点亮
- 键盘可访问、`prefers-reduced-motion` 降级
- `Ctrl/Cmd + P` 转单栏打印版式，可直接存 PDF
- Open Graph + JSON-LD `Person`
- 附带 `llms.txt`，给 AI 爬虫一份结构化说明

## 修改内容

- Hero 定位文案：搜索 `hero-title`
- 能力矩阵：搜索 `class="cap-cell"`
- 八个角色：搜索 `class="dogrid"`
- 生成器规则：脚本里的 `SIZE_MOVE` / `IND_CUT` / `PAIN_PROJ` / `PAIN_KPI` / `PAIN_RISK`
- 项目卡片：搜索 `class="work-grid"`
- 技术栈：搜索 `class="stack"`，`span class="core"` 是橙色高亮项
- 配色：`<style>` 顶部的 `:root` 与 `html[data-theme="dark"]`
